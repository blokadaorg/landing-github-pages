Guider för Blokada Cloud

Steg-för-steg-guider för att blockera reklam och spårare på router, tv, dator och mobil med Blokada Cloud.

Blokada Cloud blockerar reklam och spårare via DNS, så det fungerar även på enheter som inte kan köra en annonsblockerare. Välj din enhet eller tjänsten du byter från.

  • Ett alternativ till Pi-hole som inte kräver någon hårdvaraFlytta hemmets reklamblockering från Pi-hole till Blokada Cloud, eller behåll din Pi-hole och skicka dess uppslag via Blokada.
  • Mullvad DNS läggs ner. Behåll reklamblockeringen med Blokada CloudMullvad stänger sin publika DNS den 2 november 2026. Så flyttar du telefon, dator och router till Blokada Cloud innan dess och behåller reklamblockeringen.
  • Blockera reklam i hela nätverket med reklamblockering i routernStäll in Blokada Cloud i routern en gång och skydda alla enheter hemma, även tv, spelkonsoler och smarta högtalare som inte kan köra en annonsblockerare.
  • Blockera reklam på Android med privat DNSAnvänd Androids inbyggda privata DNS med Blokada Cloud och blockera reklam och spårare i alla appar, på wifi och mobildata, utan att installera någon app.
  • Blockera reklam på iPhone, iPad, Mac och Apple TVInstallera en DNS-profil för Blokada Cloud och blockera reklam och spårare i hela systemet på iPhone, iPad, Mac och Apple TV, med krypterad DNS och utan app.
  • Blockera reklam i Chrome, Firefox, Edge och Brave med DNS över HTTPSAnge Blokada Cloud som säker DNS i webbläsaren och blockera reklam och spårare på alla datorer, även jobbdatorer där du inte kan installera appar.

Blokada Cloud

Blockerar reklam och spårare på alla enheter i hemmet. Du ställer in det en gång i DNS-inställningarna, utan app på tv:n, konsolen eller routern.
